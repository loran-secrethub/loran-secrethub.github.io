Short write-up · Python

DOCX to XML Converter

Reads Word lessons marked with simple tags, turns them into structured XML for InDesign, and makes a QR code for every link. A whole folder, one command.

  1. Tagged Word lessonwriters mark each part
  2. Python parserone command
  3. XML + QR codesready for InDesign

1What goes in: a Word lesson 

[ENGAGE]
[LESSON_TITLE]Float or Sink?[/LESSON_TITLE]
[BODY]Have you ever pushed a beach ball underwater?[/BODY]
https://example.com/float-video
[/ENGAGE]

Writers mark each part with a tag

2What comes out: clean XML 

<lesson>
  <engage>
    <lessonTitle>Float or Sink?</lessonTitle>
    <body>Have you ever pushed a beach ball underwater?</body>
    <qrLink>https://example.com/float-video</qrLink>
  </engage>
</lesson>

Sections, text and links, ready for InDesign

4The result

Made for my team. I wrote a step-by-step guide so anyone can run it, no coding needed.
